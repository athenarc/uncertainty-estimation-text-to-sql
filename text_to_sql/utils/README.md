To run the OmniSQL and XiYan models, please follow the instructions below:

1. Get build_contents_index.py and process_dataset.py from the OmniSQL repository (https://github.com/RUCKBReasoning/OmniSQL/tree/d3bdf97b2033992a037a2d5d91b82c32b6eafb54/train_and_evaluate)
2. Copy them to the text_to_sql/utils/omnisql_utils directory.
3. Get m_schema.py, schema_engine.py and utils.py from the M-Schema repository (https://github.com/XGenerationLab/M-Schema). Use these commits: [m_schema.py](https://github.com/XGenerationLab/M-Schema/blob/44cc888ec4123149dadf1bb708aa0a7f63d91c5e/m_schema.py), [schema_engine.py](https://github.com/XGenerationLab/M-Schema/blob/372a39625210eb76a6f137d20ca3c53409f9dd27/schema_engine.py), [utils.py](https://github.com/XGenerationLab/M-Schema/blob/a1029fe33909a0662422dc7a14268f660ad77b99/utils.py)
4. Copy them to the text_to_sql/utils/xiyan_utils directory.
