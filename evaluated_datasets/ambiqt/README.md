To use the AmbiQT dataset, please follow the instructions below:

1. Download the dataset (benchmark folder) and the db-content.zip from the AmbiQT repository (https://github.com/testzer0/AmbiQT/tree/master)
2. Copy the downloaded dataset and the unzipped db-content from the repository to the evaluated_datasets/ambiqt/storage directory.
3. Run the generate_modified_databases.py script to create the modified databases for evaluation.
